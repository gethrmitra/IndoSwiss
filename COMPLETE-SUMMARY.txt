==============================================================================
                      🎨 THEME CUSTOMIZATION
==============================================================================

The BIGGEST new feature: admins can now customize the entire color theme!

HOW TO USE:
1. Open admin.html
2. Click "🎨 Branding" in the sidebar
3. See the "Theme Color" section
4. Click the color picker or enter a hex code
5. Click "Apply Theme"
6. Open the public store and refresh — colors update instantly!

The accent color applies to:
  ✓ All buttons (primary action buttons)
  ✓ Links and highlights
  ✓ Product discount prices
  ✓ Brand tabs active state
  ✓ Filter buttons active state
  ✓ Cart total amount
  ✓ Campaign badges
  ✓ Stock status indicators

PRESET COLORS TO TRY:
  • Gold (Default):     #b8860b
  • Rose Gold:          #d4876e
  • Silver:             #c0c0c0
  • Deep Blue:          #1e3a8a
  • Emerald:            #10b981
  • Burgundy:           #991b1b
  • Copper:             #b87333
  • Platinum:           #e5e4e2

The color automatically adjusts for both light and dark themes.

==============================================================================
                         DATA FLOW & STORAGE
==============================================================================

All data flows through localStorage (5-10MB browser storage):

  ┌─────────────────┐
  │  Admin Panel    │  (add products, set colors, create campaigns)
  │  admin.html     │
  └────────┬────────┘
           │ save to localStorage
           ↓
  ┌─────────────────────────────────────────┐
  │  Browser localStorage                   │
  │  • brands                               │
  │  • products (with images)               │
  │  • discounts                            │
  │  • campaigns                            │
  │  • themeColor ← NEW!                    │
  │  • storeName, storeTagline              │
  │  • cart                                 │
  │  • FAQs, policies, etc.                 │
  └────────────┬────────────────────────────┘
               │ read from localStorage
               ↓
  ┌─────────────────┐
  │ Public Store    │  (displays to customers)
  │  index.html     │
  └─────────────────┘

Real-time sync: When admin saves something, customers see it on refresh.

==============================================================================
                        STORAGE & LIMITS
==============================================================================

Browser localStorage: 5-10MB
  • Enough for ~50-100 products with images
  • Base64-encoded images take ~33% more space
  • To increase: Use Imgur for unlimited image hosting

To Back Up Data:
  1. Open browser DevTools (F12)
  2. Application → Local Storage → Your Domain
  3. Copy the entire localStorage as JSON
  4. Save as backup.json

To Restore:
  1. Open localStorage in DevTools
  2. Paste the backed-up data
  3. Refresh the page
