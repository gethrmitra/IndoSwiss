🚀 Deploy IndoSwiss to GitHub Pages

Fix the 404 error and get your store live

Step 1: Check Your Files on GitHub

First, verify that your files are actually on GitHub:

  1. Go to: https://github.com/gethrmitra/IndoSwiss
  2. Look at the file list on the main page

Question: Do you see these 3 files?

✓ admin.html (40KB)
✓ index.html (24KB)
✓ checkout.html (10KB)

If YES: Go to Step 2
If NO: Go to Step 1b (Upload)

Step 1b: Upload Files to GitHub

If you don't see the files, upload them now:

  1. Go to: https://github.com/gethrmitra/IndoSwiss
  2. Click the green Code ↓ button
  3. Click Upload files
  4. Drag and drop these 3 files:
    • admin.html
    • index.html
    • checkout.html
  5. Scroll down and click Commit changes (green button)
  6. Wait 10-20 seconds for upload to complete
✓ Files uploaded! Now go to Step 2

Step 2: Enable GitHub Pages

Tell GitHub to host your store:

  1. Go to: https://github.com/gethrmitra/IndoSwiss
  2. Click Settings (top right, gear icon)
  3. On the left sidebar, click Pages
  4. Under "Build and deployment":
    • Source: Select Deploy from a branch
    • Branch: Select main
    • Folder: Select / (root)
  5. Click Save button
⚠️ Wait 2-3 minutes for GitHub to deploy. Don't refresh yet!

Step 3: Test Your Store

After 2-3 minutes, visit your store:

https://gethrmitra.github.io/IndoSwiss/

You should see:

  • ✓ IndoSwiss logo at the top
  • ✓ Brand tabs (Rolex, Omega, etc.)
  • ✓ Filter buttons (All, Mens, Womens, Unisex)
  • ✓ Product grid with images
  • ✓ Shopping cart
✓ If you see your store → It's working! 🎉

⚠️ Still Getting 404?

Try these fixes:

  1. Clear browser cache:
    • Windows: Press Ctrl + Shift + Delete
    • Mac: Press Cmd + Shift + Delete
  2. Try incognito/private mode:
    • Open new incognito window
    • Visit the link again
  3. Check repository is PUBLIC:
    • Go to repo → Settings
    • Scroll to "Visibility"
    • Should say "Public"
    • If "Private", click "Change to public"
  4. Verify Pages is enabled:
    • Settings → Pages
    • Should show blue message: "Your site is ready at https://gethrmitra.github.io/IndoSwiss/"
  5. Wait longer:
    • First-time deployments can take 5-10 minutes
    • Wait 10 minutes and try again

✅ Your Store is Live!

Now you can:

  • Open admin.html locally to add brands, products, discounts, campaigns
  • Share your store URL: https://gethrmitra.github.io/IndoSwiss/
  • Customers can browse, search, and add to cart
  • Everything is live and free! 🎉

Remember: All data is stored locally in your browser. To make changes, edit in admin.html then refresh the store page.
