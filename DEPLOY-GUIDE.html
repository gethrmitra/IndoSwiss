Push Your Code

Run in terminal:

git remote add origin https://github.com/YOUR_USERNAME/ecommerce-store.git git branch -M main git push -u origin main

Replace YOUR_USERNAME with your GitHub username

3

Enable GitHub Pages

In your GitHub repo:

  • ✓ Settings → Pages
  • ✓ Source: main branch
  • ✓ Folder: / (root)
  • ✓ Click "Save"

Wait 1-2 minutes for deployment
