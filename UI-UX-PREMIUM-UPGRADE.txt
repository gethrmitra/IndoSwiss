================================================================================
                            DESIGN SYSTEM
================================================================================

COLORS (Light Mode):
  --luxury-dark: #0a0a0a (text on light)
  --luxury-bg: #f5f3f0 (light neutral background)
  --luxury-card: #ffffff (card/section background)
  --luxury-text: #1a1a1a (primary text)
  --luxury-text-light: #6b6b6b (secondary text)
  --luxury-accent: #c9a961 (gold buttons, highlights)
  --luxury-accent-dark: #a68442 (darker gold for hover)
  --border-subtle: #e8e6e3 (borders, dividers)

COLORS (Dark Mode):
  --luxury-bg: #1a1a1a (dark background)
  --luxury-card: #252525 (slightly lighter for cards)
  --luxury-text: #f5f3f0 (light text)
  --luxury-accent: #d4af37 (brighter gold)
  --luxury-accent-dark: #e8c547 (brightest gold)
  --border-subtle: #3a3a3a (visible borders on dark)

TYPOGRAPHY:
  Display: Playfair Display (serif, 700 weight)
           Used for headings, section titles, logos
           Letter-spacing: 0.5px to 2px

  Body: Inter (sans-serif, 400-600 weights)
        Used for all body text, buttons, labels
        Font-size: 13px to 15px
        Line-height: 1.6 to 1.7

  Premium: Cormorant Garamond (serif, 400-700 weights)
           Used for pricing displays
           Letter-spacing: 0.5px

SPACING:
  Containers: 32px-48px padding (desktop), 16px-20px (mobile)
  Gaps: 16px-32px between sections
  Cards: 24px-32px internal padding
  Buttons: 14px-16px padding (h), 24px-32px padding (h)

BUTTONS:
  Primary (CTAs): Gold background, white text, uppercase, uppercase letter-spacing
  Secondary: Transparent bg, border, text color, uppercase
  Hover state: Darker gold, slight lift (transform: translateY(-2px))
  Disabled: 50% opacity

INTERACTIONS:
  Hover effects: Scale images (1.05), shadow lift, color change
  Transitions: 0.2s-0.4s ease for all state changes
  Animations: Pulse for live indicators, slide for cart, scale for success

RESPONSIVE BREAKPOINTS:
  Mobile: 0px - 400px (single column, stacked)
  Tablet: 400px - 768px (2 columns)
  Desktop: 768px+ (3+ columns, full layout)

                      STRIPE SETUP FOR PRODUCTION
================================================================================

When ready to accept real payments:

1. Get Production Keys
   → Visit: https://dashboard.stripe.com/apikeys
   → Copy "Publishable key"
   → Copy "Secret key" (keep secret!)

2. Update Checkout File
   → In checkout-premium.html, find: const stripe = Stripe('pk_test_...')
   → Replace with: const stripe = Stripe('pk_live_YOUR_LIVE_KEY')
   → Keep test mode during testing

3. Backend Setup (Optional)

   → For production: set up backend to verify payments
   → Backend URL: your server
   → Webhook: receives payment confirmation
