  3. Visibility: PUBLIC
  4. Click "Create repository"

STEP 2: Push Your Code (2 minutes)
  Run in terminal:

  git remote add origin https://github.com/YOUR_USERNAME/ecommerce-store.git
  git branch -M main
  git push -u origin main

  (Replace YOUR_USERNAME with your GitHub username)

STEP 3: Enable GitHub Pages (1 minute)
  1. Go to your GitHub repo
  2. Settings → Pages
  3. Source: main branch, / (root) folder
  4. Click Save
  5. Wait 1-2 minutes

================================================================================
                      ADD PAYMENT PROCESSING
================================================================================

To accept Stripe payments:

1. Create Stripe account at https://stripe.com (free signup)

2. Get your API keys from Developers → API Keys
   - Publishable Key: pk_test_...
   - Secret Key: sk_test_... (keep private!)

3. Add Publishable Key to checkout.html (line ~135):
   const STRIPE_PUBLISHABLE_KEY = 'pk_test_YOUR_KEY_HERE';

4. Test with card: 4242 4242 4242 4242 (any future date, any CVC)

5. Switch to live keys after testing

No monthly fees. Only 2.9% + 30 cents per transaction.

================================================================================
                      OPTIONAL: IMAGE HOSTING
================================================================================

For unlimited media storage (instead of 5-10MB browser limit):

OPTION A: Imgur (Recommended - Easiest)
  1. Sign up at https://imgur.com/register
  2. Create API Client at https://imgur.com/oauth2/addclient
     - Choose "Anonymous use"
  3. Copy Client-ID
  4. Add to admin-master.html (line ~670):
     const IMGUR_CLIENT_ID = 'YOUR_CLIENT_ID';
  5. Media uploads now use Imgur links

OPTION B: GitHub
  1. Create /images folder in your repo
  2. Commit images: git add images/ && git push
  3. Link them in media uploads

OPTION C: Cloudinary
  1. Sign up at https://cloudinary.com
  2. Get API credentials
  3. Use web upload widget
