==============================================================================
                    HOW TO USE INVENTORY DASHBOARD
==============================================================================

TO VIEW ANALYTICS:
  1. Open admin.html
  2. Click "📈 Inventory" in sidebar
  3. See three sections:
     • 👁️ Product Views (top 10)
     • 🛒 Cart Additions (top 10)
     • 📊 Inventory Summary (all products)

TO UNDERSTAND THE DATA:
  • Views = How many customers looked at the product
  • In Cart = How many added to cart (shows interest)
  • Stock = Current inventory level
  • Status = Stock condition (Good/Low/Out)

TO EXPORT DATA:
  1. Go to 📈 Inventory section
  2. Click "Export Data" button
  3. JSON file downloads (indoswiss-analytics-timestamp.json)
  4. Use for analysis or backup

TO RESET DATA:
  1. Go to 📈 Inventory section
  2. Click "Reset Analytics" button
  3. Confirm when asked
  4. All tracking data clears (cannot undo!)
