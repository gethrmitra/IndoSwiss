==============================================================================
                    MEDIA UPLOAD IN DETAIL
==============================================================================

PHOTO UPLOAD:
  Location: admin-master.html → Media section → "Showcase Photos"
  How to use:
    • Drag & drop photos into the area, OR
    • Click the area to browse files
  Storage:
    • Default: Browser storage (5-10MB limit)
    • Better: Use Imgur (unlimited, see below)
  Formats: JPG, PNG, WebP, GIF
  Where they appear: store.html → scroll down → "Brand Gallery"

VIDEO UPLOAD:
  Location: admin-master.html → Media section → "Showcase Videos"
  How to use:
    • Same as photos - drag & drop or click to browse
  Storage:
    • Default: Browser storage (5-10MB limit)
    • Better: Use Imgur (unlimited)
  Formats: MP4, WebM, OGG
  Where they appear: store.html → scroll down → "Brand Gallery"

UNLIMITED STORAGE (IMGUR):
  1. Go to https://imgur.com/register → Create account
  2. Go to https://imgur.com/oauth2/addclient → Create API Client
  3. Choose "Anonymous use" (no callback URL)
  4. Copy your Client-ID
  5. Open admin-master.html in text editor
  6. Find line ~670: const IMGUR_CLIENT_ID = '';
  7. Paste: const IMGUR_CLIENT_ID = 'your-client-id-here';
  8. Save and reload admin panel
  9. Now media uploads use Imgur (permanent links!)

                    EVERYTHING SYNCS AUTOMATICALLY

Admin → Store (Instant Sync):
  ✅ Add product → appears in store immediately
  ✅ Add brand → appears as tab immediately
  ✅ Upload photo/video → appears in gallery
  ✅ Edit About Us → updates in store
  ✅ Edit policies → updates in store
  ✅ Add FAQ → updates in store
  ✅ Change company info → updates in footer
  ✅ Change logo/name/tagline → updates in header

How it works:
  • All data stored in browser localStorage
  • When you change something in admin, it saves to localStorage
  • When you open store.html, it reads from localStorage
  • Both admin and store read/write to same localStorage
  • Changes appear instantly when you refresh store
