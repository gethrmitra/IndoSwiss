FIX: GitHub Pages 404 Error

STEP 1: Check Your Repository Name
  • Go to https://github.com/YOUR_USERNAME/ecommerce-store
  • Look at the top left - it should say "ecommerce-store"
  • If the repo has a different name, the URL changes!
  • Example: If repo is "my-store", URL is:
    https://YOUR_USERNAME.github.io/my-store/

STEP 2: Verify GitHub Pages Settings
  1. Go to your repo on GitHub
  2. Click Settings (top menu)
  3. Scroll left sidebar → Click "Pages"
  4. Under "Source":
     • Branch: main (MUST be "main", not "master")
     • Folder: / (root)
     • Click Save
  5. Wait 2-5 minutes

STEP 3: Check Deployment Status
  • Still in Pages section
  • Look for status message (should show green checkmark "Active")
  • If it shows "Building", wait more
  • If it shows "Failed", see troubleshooting below

STEP 4: Try Your Store
  Once "Active" status appears:
  
  https://YOUR_USERNAME.github.io/ecommerce-store/
  
  If repo name is different, replace "ecommerce-store" with your actual repo name

STEP 5: Test Individual Files
  If main URL doesn't work, try:
  
  https://YOUR_USERNAME.github.io/ecommerce-store/index.html
  https://YOUR_USERNAME.github.io/ecommerce-store/store.html
  https://YOUR_USERNAME.github.io/ecommerce-store/admin-master.html

STEP 6: Clear Cache
  • Try in incognito/private window (F12 → don't cache)
  • Or: Ctrl+Shift+Delete (clear browser cache)
  • Then reload the page

================================================================================
TROUBLESHOOTING
================================================================================

If Still Getting 404:

1. Check Repository is PUBLIC
   • Settings → General
   • Danger Zone → Visibility
   • Should say "Public"
   • If "Private", click "Change to public" and confirm

2. Verify Files Were Pushed
   • Terminal:
     git status
   • Should show "nothing to commit"
   • If files listed, run:
     git add .
     git push origin main

3. Check Branch Name
   • Terminal:
     git branch
   • Should show "main"
   • If shows "master", rename:
     git branch -M main
     git push -u origin main

4. Pages Status is "Failed"?
   • Click the "Details" link next to "Failed"
   • See the error message
   • Most common: index.html missing in root (should be there!)

5. Still Not Working?
   • Try deleting and recreating Pages:
     Settings → Pages → Change source to "None"
     Wait 30 seconds
     Change source back to "main" / "root"
     Save and wait 2-5 minutes
